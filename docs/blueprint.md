# **App Name**: Cronofábula

## Core Features:

- Context-Aware AI Narrator: An AI narrator that interprets the campaign's current state and roleplays NPCs using strictly filtered visibility rules to prevent metagaming.
- Node-Based Live Map: A persistent navigation system with point-to-point travel, dynamic fog-of-war, and GM-controlled secret locations.
- Session Chronicle Builder: Uses a generative AI tool to transform combat logs and chat messages into epic narrative summaries that build a permanent campaign memory.
- GM Master-Key Control: An approval system that ensures all AI-suggested rewards, XP, and map changes only become canon after GM confirmation.
- Mechanical Combat Arena: A zone-based battle visualizer that calculates HP, AC, and rolls, then uses AI to narrate the results into dramatic prose.
- Persistent Item & Journal Tracker: Real-time management of character items and journals that lose functionality if dropped, lost, or destroyed within the game world.
- Rules Assistant Bot: An AI-powered tool to explain D&D SRD mechanics, suggest test CDs, and interpret conditions based on context.

## Style Guidelines:

- A dark scheme featuring a deep Purple Primary (#7B42BC) evoking magic, with a desaturated Midnight Navy Background (#12161F).
- A contrasting Sapphire Accent (#424BBC) used for active turn indicators and interactive nodes.
- A pairing of 'Literata' for all literary body text and narrative chronicles to provide a vintage formal feel, with 'Inter' for technical UI elements.
- Code and dice-roll command displays utilize 'Source Code Pro' for clarity.
- Skeuomorphic icon sets depicting mystical objects: hourglasses, tattered scrolls, and glowing arcane runes.
- The interface mimics a centered leather-bound 'Mesa Viva', with sidebar-locked inventory and character statuses.
- Subtle, ethereal fades and particle effects when AI narrator responses are 'channeled' into the chat.
