# CRONOFÁBULA — Sistema Visual e Temas

## 1. Resumo Executivo

O **Cronofábula** é uma plataforma de RPG com IA criada para manter campanhas vivas mesmo quando o grupo não consegue se reunir com frequência.

A identidade visual aprovada combina:

- tempo;
- fantasia;
- magia;
- reunião;
- crônicas antigas;
- personalização por personagem.

A proposta visual é que o sistema pareça um ambiente de RPG vivo, como se cada campanha fosse registrada em um grimório, em uma mesa arcana ou em uma crônica antiga.

O sistema terá uma **marca fixa** e **temas prontos para jogadores**, baseados principalmente em **classe** e complementados por **raça/espécie**.

## 5. Estratégia de Cores

A estratégia aprovada é:

```txt
Marca fixa + temas prontos por jogador/personagem.
```

### Marca fixa

A identidade oficial do Cronofábula deve permanecer consistente em:

- logo;
- landing page;
- tela de login;
- materiais institucionais;
- documentação;
- onboarding.

### Temas do jogador/personagem

O jogador poderá escolher ou receber temas prontos com base em:

- classe;
- raça/espécie;
- combinação especial de classe + raça, quando existir.

A personalização será controlada no MVP. O sistema **não deve liberar qualquer cor livremente no início**, para evitar problemas de contraste, poluição visual e quebra de identidade.

## 7. Conceito da Logo

### Conceito aprovado

```txt
Ampulheta + círculo de pessoas + livro ou d20 no centro.
```

### Elementos principais

A logo deve representar:

- pessoas se reunindo para jogar;
- o tempo separado para a campanha;
- a mesa de RPG;
- a continuidade das histórias;
- o equilíbrio entre fantasia e sistema;
- uma fábula que atravessa o tempo.

### Direção visual

A logo deve ter:

- uma ampulheta estilizada;
- curvas da ampulheta sugerindo pessoas reunidas;
- composição circular ou semicírculo para transmitir encontro;
- um livro aberto, dado d20 ou combinação sutil no centro;
- aparência de medalhão, selo ou emblema arcano.

### Interpretação simbólica

```txt
A ampulheta representa o tempo.
O círculo de pessoas representa a mesa e o grupo.
O livro/d20 representa a narrativa e o jogo.
O medalhão representa a crônica viva da campanha.
```

## 8. Tipografia e Letras Arcanas

### Direção aprovada

A tipografia do Cronofábula deve misturar:

- estilo arcano;
- inspiração nórdica/rúnica;
- fantasia medieval;
- legibilidade de produto digital.

### Regra principal

```txt
A marca deve parecer mística, mas continuar legível.
```

A palavra **Cronofábula** não deve ser transformada em runas puras. A recomendação é usar uma fonte serifada, medieval ou editorial como base, com cortes e detalhes inspirados em runas.

### Estilo desejado

```txt
Um nome escrito como se fosse parte de uma profecia antiga, mas ainda legível como marca moderna.
```

### Aplicações tipográficas

#### Logo principal

Uso de letras legíveis com detalhes arcanos/rúnicos.

Usar em:

- logo;
- landing page;
- tela de login;
- dashboard;
- cabeçalhos importantes.

#### Escrita arcana decorativa

Versão mais simbólica e ritualística.

Usar em:

- fundos;
- bordas de cards;
- medalhões;
- loading;
- abertura de sessão;
- selos de campanha;
- círculos mágicos;
- textura de grimório.

### Possíveis detalhes nas letras

| Letra/Elemento | Ideia visual |
|---|---|
| C | Meia-lua, portal ou arco |
| O | Relógio mágico, olho arcano, d20 ou portal |
| A | Forma rúnica, torre ou lança |
| Á | Acento como runa, estrela, chama ou marca de destino |
| F | Corte nórdico/angular |
| BULA | Fluxo mais narrativo, lembrando escrita em pergaminho |

## 15. Regras de Usabilidade

### Manter consistência

Todos os temas devem manter a mesma estrutura de tela.

O que pode mudar:

- cores;
- ícones;
- textura;
- borda;
- microfrases;
- fundos;
- estilo dos cards;
- ornamentos.

O que não pode mudar:

- localização dos botões principais;
- navegação;
- fluxo da sessão;
- regras de permissão;
- hierarquia da informação;
- leitura do chat;
- acessibilidade básica.

### Evitar poluição visual

Mesmo temas caóticos, como Goblin, devem continuar legíveis.

### Contraste obrigatório

Todo tema deve garantir boa leitura em:

- chat da sessão;
- ficha de personagem;
- rolagens;
- botões principais;
- alertas;
- histórico.

### Temas não alteram regras

O tema é visual e narrativo. Ele não deve alterar regras do sistema de RPG.

## 19. Riscos, Limitações e Próximos Passos

### Riscos

- Criar tema demais antes do MVP funcional.
- Deixar a interface bonita, mas pesada.
- Temas exagerados prejudicarem leitura.
- Letras arcanas ficarem ilegíveis.
- Combinações classe + raça aumentarem demais o escopo.

### Limitações

- No MVP, os temas devem ser visuais, não funcionais.
- Nem toda combinação precisa ter nome especial.
- A estrutura principal da tela deve ser igual em todos os temas.
- A IA, o banco, a sessão, a ficha e a rolagem continuam sendo prioridades superiores à estética.
